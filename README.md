# Quant Portfolio Modeling Engine

A quantitative portfolio analysis engine built in Python from first principles.

The goal of this project is to implement and understand the mathematics behind portfolio analysis rather than relying entirely on black-box financial libraries.

## Planned Features

- Historical price analysis
- Simple returns
- Expected returns
- Variance and volatility
- Covariance and correlation
- Portfolio expected return
- Portfolio variance
- Diversification analysis
- Sharpe ratio
- Beta
- Linear regression
- Annualization
- Monte Carlo portfolio simulation
- Portfolio optimization
- Efficient frontier
- Backtesting
- Data visualization

## Project Philosophy

Core financial calculations are implemented manually from their mathematical formulas before being compared against library implementations.

This allows the project to demonstrate both quantitative-finance understanding and Python programming skills.

## Technology

- Python
- NumPy
- pandas
- Matplotlib
- Jupyter
- pytest
